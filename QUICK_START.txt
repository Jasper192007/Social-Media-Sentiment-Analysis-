QUICK START (3 steps)
1. Install Python 3.9 or newer from python.org (tick "Add Python to PATH" on Windows).
2. Open this folder in VS Code / terminal and run:
       Windows :  double-click run_app.bat        (or:  pip install -r requirements.txt)
       Mac/Linux: ./run_app.sh
3. If not using the scripts:  streamlit run app.py   -> opens http://localhost:8501

Everything else (dataset, trained models) is already included. No NLTK/data downloads, no API keys.
Run the tests:  python tests/test_pipeline.py
If you see a model-loading / scikit-learn version message: python train_all.py  (about 1 minute)
