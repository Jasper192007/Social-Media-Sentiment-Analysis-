# Social Media Sentiment Analysis for Brand Performance Prediction

## 1. Project overview
A working AI/ML application that reads social-media posts about a brand, cleans them with NLP, classifies
their sentiment, finds the topics people talk about, calculates a **Social-Media-Based Brand Performance Score**
(0–100), studies the trend over time and predicts whether the brand's social-media performance is
**Improving, Stable or Declining**. Everything is shown in a Streamlit dashboard.

> ⚠️ It measures **online perception only**. It does not measure or predict sales, revenue, stock price or any
> financial result, and its predictions are not guarantees.

## 2. Problem statement
Brands receive thousands of comments a day. Reading them manually is impossible, and simple counts hide *what*
people are unhappy about and *whether* opinion is getting better or worse. This project automates that analysis.

## 3. Objectives
1. Clean and prepare raw social-media text.
2. Classify statements as Positive / Neutral / Negative.
3. Identify the topics being discussed.
4. Compute a transparent brand performance score.
5. Analyse historical trends (day / week / month).
6. Predict Improving / Stable / Declining.
7. Provide an interactive dashboard and a social media text analyzer.

## 4. Features
- CSV upload with validation and friendly error messages (empty file, missing columns, bad dates, duplicates…)
- Reusable preprocessing (lowercase, URLs, mentions, hashtags, emojis, punctuation, stop words, contractions)
- Sentiment model: TF-IDF + Logistic Regression
- Keyword-based topic detection (7 topics) + top keywords
- Brand score, trend line, sentiment trend
- Random Forest performance predictor (time-based train/test split)
- Model Evaluation page (accuracy, precision, recall, F1, confusion matrix — computed, not hard-coded)
- Optional MySQL storage (project works fully without it)

## 5. Technologies
Python · Pandas · NumPy · Scikit-learn (TF-IDF, Logistic Regression, Random Forest) · Plotly · Streamlit · Joblib ·
MySQL (optional).  No NLTK downloads and no internet are needed at run time.

## 6. System workflow
```
CSV Data → Validation → Preprocessing → TF-IDF → Sentiment Model → Topic Analysis
        → Brand Score → Trend Analysis → Random Forest Prediction → Streamlit Dashboard
```

## 7. Architecture
| Layer | File(s) | Job |
|---|---|---|

| Glue | `analysis/pipeline.py` | CSV → processed table → prediction |
| Training | `training/*.py`, `train_all.py` | train and save models |
| UI | `app.py` | Streamlit dashboard |
| DB (optional) | `database/` | MySQL schema + save functions |

## 8. Dataset format
CSV with columns:

| column | required | example |
|---|---|---|
| `statement` | yes | The product is amazing 😍 |
| `brand` | yes | NovaWear |
| `date` | yes | 2026-01-01 |
| `sentiment` | no (Positive/Neutral/Negative) | Positive |
| `engagement` | no (likes/shares number) | 42 |

Common alternative names (`text`, `tweet`, `company`, `timestamp`, `likes`…) are renamed automatically.

**Included data:** `dataset/social_media_data.csv` is **synthetic** (generated by `dataset/generate_sample_data.py`,
fictional brands, ~57k statements from Jan 2025 to Sep 2026, 7% deliberately noisy labels). It exists so the whole
system can run offline. For real results use a real dataset (e.g. from Kaggle) in the same format.
`dataset/example_upload_no_labels.csv` is a small file without sentiment labels to try the upload feature.

## 10. Installation
Requires **Python 3.11+**. The bundled models use scikit-learn 1.8.0.

**Easiest (Windows):** double-click `run_app.bat`. **Mac/Linux:** `./run_app.sh`.

**Manual:**
```powershell
py -3.14 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```
On Mac/Linux, create and activate the environment with `python3 -m venv .venv` and `source .venv/bin/activate`.

## 11. How to train the models
Trained models are already included. To retrain (e.g. after changing the dataset or if you see a
scikit-learn version warning):
```powershell
python train_all.py
```
To regenerate the synthetic dataset first: `python dataset/generate_sample_data.py`.
(The dashboard also has a "Train models now" button if model files are missing.)

## 12. How to run the application
```powershell
python -m streamlit run app.py
```
Open http://localhost:8501. Run the tests with `python tests/test_pipeline.py`.

## 13. Brand Performance Score
```
Score = (Positive% × 1) + (Neutral% × 0.5) + (Negative% × 0)
```
Example: 70% positive, 20% neutral, 10% negative → 70 + 10 + 0 = **80 / 100**.
Weights can be changed in `config.py`. This is a *Social-Media-Based Brand Performance Score*, not financial performance.

## 14. Prediction model — what "Improving / Stable / Declining" means
For each brand and each **week**, features are built from that week and its history: positive/neutral/negative %,
mentions, average engagement, previous score, score change, 3- and 6-week rolling scores, trend slopes, and the
share of negative service-related statements (complaint frequency).
Training label: compare the **average score of the next 2 weeks** with the **average of the last 3 weeks**:
more than +2 points → Improving, less than −2 → Declining, otherwise Stable.
Train/test split is by **time** (oldest 75% of weeks train, newest 25% test) so the model never sees the future.

## 16. Model evaluation (results of the run shipped in this zip, on the SYNTHETIC dataset)
| Model | Accuracy | Precision (weighted) | Recall (weighted) | F1 (weighted) |
|---|---|---|---|---|
| Sentiment (Logistic Regression) | 0.926 | 0.926 | 0.926 | 0.925 |
| Performance (Random Forest) | 0.467 | 0.439 | 0.467 | 0.448 |

- Sentiment: 11,503 test statements. High because the synthetic text is simple; real-world accuracy would be lower.
- Performance: only 120 test weeks (6 brands). Accuracy 46.7% vs **31.7%** for always guessing the most common class.
  It beats the baseline but is **modest** – predicting future sentiment is genuinely hard. Do not present it as highly accurate.
- Exact numbers and confusion matrices are regenerated each time you train (`model/*_metrics.json`, Model Evaluation page).

## 17. Limitations
- Included data is synthetic; results on real data will differ.
- Keyword topic detection misses sarcasm, slang and unseen words.
- Sentiment model cannot reliably detect sarcasm or mixed feelings.
- Score reflects only the sampled social-media comments (sampling bias, bots, fake reviews).
- Performance model trained on few brands/weeks; needs ≥ 6 weeks of history per brand to predict.
- English text only. Social-media perception ≠ sales or stock price.
